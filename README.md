# Ethan Levy

Environmental data analysis, geospatial modelling, and reproducible Python workflows.

[Portfolio and study reports](https://ethannol.github.io/portfolio/)

My projects use public earth-science data to examine how sampling, measurement,
and modelling choices affect a conclusion. Each study includes its question,
results, limitations, data provenance, and code.

## Selected studies

| Project | Question and approach |
| --- | --- |
| [Groundwater audit](https://github.com/ethannol/groundwater-audit) | Do apparent water-quality trends survive comparisons at the same wells? Censored measurements, changing sample composition, and a bounded evaluation of AI-assisted analysis. |
| [Mineral prospectivity](https://github.com/ethannol/mineral-prospectivity) | How much predictive performance survives spatial validation? Geochemical features, spatial cross-validation, and laboratory effects in Nevada gold-producer data. |
| [Animas River after Gold King](https://github.com/ethannol/animas-gold-king) | Can a lasting change be separated from flow variation and a nearby treatment intervention? Interrupted time series and sensitivity analysis. |
| [Produced-water lithium](https://github.com/ethannol/produced-water-lithium) | What can a compiled water-chemistry database support about lithium screening? Missingness, dataset effects, uncertainty, and prediction across basins. |

## Tools and worked examples

- [Statistics cheat sheet](https://github.com/ethannol/stats-cheatsheet): runnable examples for environmental and mining data, with assumptions and interpretation.
- [Cairn](https://github.com/ethannol/cairn): verification and reproducibility tooling for AI-assisted analysis.
- [Groundwater BI](https://github.com/ethannol/groundwater-bi): a dbt/DuckDB warehouse, offline LookML validation, and authenticated dashboard embedding. Hosted BI demonstrations are not all complete.

The study READMEs describe how AI was used and distinguish recorded evidence from
claims the data cannot support.
